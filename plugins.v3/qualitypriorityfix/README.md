# 洗版候选优先级修复

此插件针对 MoviePilot v3.2.2 搜索恢复站点临时下载地址时，同页其他候选优先级可能丢失的问题。启用后，在候选提交前按当前订阅规则重新筛选和排序；影响采用同一搜索扫描流程的全部订阅，不修改站点账号、规则或主程序磁盘文件。

插件使用主程序内部接口，并在内存中包装选种函数。仅当版本为 v3.2.2、搜索代码 SHA-256 为已验证值且目标函数未被其他插件替换时启用。将来升级后，即便插件能重新安装，也必须重新验证和适配；不兼容时插件显示未生效并发出本地警告，主程序恢复自身行为。请在继续自动订阅前确认插件状态或官方是否已经修复。

关闭插件即可恢复主程序原行为。插件不会保证站点已有最高规格资源、即时发布或始终可下载，也不会改变既有优先级规则的排序。
