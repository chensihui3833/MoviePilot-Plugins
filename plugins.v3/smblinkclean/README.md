# SMB 硬链接清理

通过 MoviePilot 的 SMB 存储直接比较服务器文件标识，检测媒体库文件删除或同路径被替换后，对应的旧下载源文件。MoviePilot 必须已配置该 SMB 存储；无需在极空间把共享映射到本地路径。

默认禁用且自动清理关闭。配置目录对后首次完整扫描仅建立基线；随后扫描检测删除或替换，重命名或旧数据仍在受监控媒体库其他路径中时不列为候选。每次扫描均需要完整读取所有配置目录；网络、权限、路径或标识不完整时本轮失败，不使用部分结果更新基线。监控根目录及其祖先、子目录、视频文件若存在符号链接或重解析点，本轮停止扫描而不会忽略它们。

部分 SMB 客户端会将符号链接存为固定长度 1067 字节的普通文件；无法只凭元数据可靠区分。为避免读取文件内容，扫描到这种大小的非目录项会保守停止，可能将同样大小的普通文件误报；不确定时保留文件并检查原因。格式依据 [Linux CIFS 实现](https://github.com/torvalds/linux/blob/master/fs/smb/client/link.c)。

目录配置每行一组 `下载目录|媒体库目录`，例如 `/源数据/电影|/电影`，可以再添加电视剧一行。全部目录必须属于 MoviePilot 同一个 SMB 共享，互不重叠；应覆盖该源目录关联的全部媒体库位置。禁止共享根目录和路径穿越。仅识别常见视频扩展名。

启用自动清理前，必须填写 MoviePilot 已连接的目标 QB 下载器名称。候选至少经过两轮完整扫描且等待十分钟；插件读取 QB 任务文件清单，以完整 SMB 映射路径精确匹配旧源文件，找不到匹配任务、QB 断线或信息不完整时保留源文件。所有匹配的 QB 任务先暂停并复查状态；删除前检查来源范围，打开源文件句柄，比较服务器卷 ID、文件 ID、大小、创建及修改时间，再次完整扫描全部媒体库目录和旧文件所在目录及 QB 清单，然后在同一打开句柄上请求删除。旧文件所在目录必须可以访问；如果它被删除或无法访问，保留候选不清理。媒体库扫描为空或复核时可见文件数量减少时只预览，不清理。

单视频种子：确认旧源已清理后，删除 QB 任务，但不让 QB 删除其他下载文件。多视频种子：先暂停整个任务，只清理已匹配且符合条件的旧视频，其余视频与任务保留；只有全部视频都由本插件确认清理，才删除 QB 任务。多个种子指向同一源文件时，必须先全部暂停；匹配、暂停或复核失败即保留源文件。种子中的非视频文件不自动删除，删除任务可能影响做种及站点考核要求。

插件在操作前保存本地意图记录；网络或程序在操作过程中异常时，可能留下暂停中的任务或待人工核对的记录，不会为了完成清理而猜测文件状态。重新配置下载器或目录前，应先处理尚未结束的种子。下载器 API 和 SMB 文件操作无法构成同一个事务，实际使用前先以独立测试种子核验。

插件停止/重启或程序重启后重新建立基线，期间的删除不会追溯，以避免用过期身份自动清理。已存在于基线前的旧文件不会被发现。扫描期间的网络开销与文件数有关；每类最多 50000 个视频文件。多集种子中的一集源文件被清理后可能使整个种子变成缺失状态。

新版本需先在用户 NAS 隔离目录验证；未验证通过前不要对生产目录启用自动清理。MoviePilot 私有存储接口或 smbprotocol 升级变化可能需要适配；失败时应检查日志和文件是否部分完成。
