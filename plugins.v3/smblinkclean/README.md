# SMB 硬链接清理

通过 MoviePilot 的 SMB 存储直接比较服务器文件标识，检测媒体库文件删除或同路径被替换后，对应的旧下载源文件。MoviePilot 必须已配置该 SMB 存储；无需在极空间把共享映射到本地路径。

默认禁用且自动清理关闭。配置目录对后首次完整扫描仅建立基线；随后扫描检测删除或替换，重命名或旧数据仍在受监控媒体库其他路径中时不列为候选。每次扫描均需要完整读取所有配置目录；网络、权限、路径或标识不完整时本轮失败，不使用部分结果更新基线。

目录配置每行一组 `下载目录|媒体库目录`，例如 `/源数据/电影|/电影`，可以再添加电视剧一行。全部目录必须属于 MoviePilot 同一个 SMB 共享，互不重叠；应覆盖该源目录关联的全部媒体库位置。禁止共享根目录和路径穿越。仅识别常见视频扩展名。

启用自动清理后，候选至少经过两轮完整扫描且等待十分钟；删除前检查来源范围，打开源文件句柄，比较服务器卷 ID、文件 ID、大小、创建及修改时间，再次完整扫描全部媒体库目录确认该 ID 已不存在，然后在同一打开句柄上请求删除。媒体库扫描为空或复核时可见文件数量减少时只预览，不清理。遇到占用、网络故障、信息不一致、符号链接或重解析点时不清理。删除源文件可能影响 QB 做种，本插件不会自动删除 QB 任务。

插件停止/重启或程序重启后重新建立基线，期间的删除不会追溯，以避免用过期身份自动清理。已存在于基线前的旧文件不会被发现。扫描期间的网络开销与文件数有关；每类最多 50000 个视频文件。多集种子中的一集源文件被清理后可能使整个种子变成缺失状态。

当前 0.1.0 需先在用户 NAS 隔离目录验证；未验证通过前不要对生产目录启用自动清理。MoviePilot 私有存储接口或 smbprotocol 升级变化可能需要适配；失败时应保持文件原样并检查日志。
