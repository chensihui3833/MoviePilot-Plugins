# AI 分集接入设计

用户已确认的目标：基于 Codex 的 BlurayEpisodes 0.4.0（5991efe446a9），保留已验证的 MoviePilot 媒体匹配、目标选择、命名、预览、硬链接/NFO 和停止行为，只替换按菜单引擎写死的识别入口。完成验证后直接发布现有插件源，随后用户已授权安装更新到NAS以进行原生文件管理预览；不执行正式媒体整理。

## 输入和流程

原来的自动/手动整理入口不变。沿用 0.4.0 的路径适配，让本地 DISC 盘从上级整季目录取得电视剧和季号；transfer provider 在普通整盘整理之前接管。非电视剧、非 BDMV 继续原流程。被接管后，未知或错误返回明确失败，不能返回 None 使整盘当单集。

整季识别交给 MoviePilot 当前已经配置的助手，不另存 API 密钥或部署模型。提示只交代季目录和逐集配对目标，不告知盘数、集数、类名或解析顺序。另说明只分析不修改，并用插件提供的 submit_bluray_mapping 工具提交机器可校验结果。工具只接受活动任务的 ID，把结果交给插件，不执行媒体写入。所有整理写入仍由原 0.4.0 executor 完成。现有助手的命令工具受宿主权限控制；这不是新增的操作系统只读沙箱。

提交字段包括 season、episodes（全季 episode、disc、title、playlist 相对路径）、evidence（盘内相对路径）、unknown。Unknown 非空不执行整理。机器校验不能独立证明任意菜单的语义；它必须检查季号、集号唯一连续、实际盘齐全、路径在源内、证据存在、MPLS 实际引用、完整视频范围、重复文件及源状态。不会根据 mtime、大小或文件编号排列补出缺失集序。

整季任务按源文件快照缓存并跨本季各盘复用。快照包含盘目录及源文件路径、大小、mtime、设备和 inode；元数据还取内容哈希。变动失效重算。单次最长等待可配置，默认 20 分钟；停止/停用时取消等待并丢弃活动任务提交权限。同步整理线程把协程派给宿主事件循环；若当前就是事件循环线程则失败，避免死锁。加载旧缓存仍要重新校验视频范围和文件状态。

## 输出

由原 native provider 调用宿主 recommend_name 生成剧集/季目录/单集文件名，不增加 Disc 子目录，完整保留原生模板路径：

剧名（按 MoviePilot 规则）/季目录（按规则）/单集 SxxExx 文件名.m2ts

保留 NFO、已有扩充信息、源/目标冲突预检、同卷硬链接和幂等执行。只调用 os.link，不复制或移动视频，跨文件系统失败。保留原盘。目标目录/分类仍完全来自 MoviePilot。

## 边界与兼容

首版面向原 0.4.0 已明确支持的本地目录型 BDMV、DISC1…完整单季和完整单视频单集。多个 PlayItem、部分视频区间、多角度不能通过整文件硬链接等价导出，明确失败。ISO 不宣称支持。助手可自主理解不同菜单；插件不内置按片名或菜单引擎匹配集序的分支，也不把现有样本叫未知盘盲测。

接口暂限定已核对的 MoviePilot >=3.1.5,<3.1.7。后台 Agent 接口为内部接口，能力不足时给出明确失败。0.5.0 恢复原 BlurayEpisodes ID 到 package.json，并提供 package.v3.json / plugins.v3 原生 V3 布局；保留另一插件但提示不要同时启用，以免 transfer provider 冲突。不会修改 package.v2.json 冒称支持 V2。只向 GitHub 发布代码及合成测试，不上传用户原盘或配置。

## 验收

运行保留的 0.4.0 全套回归；新增助手提交与任务隔离、超时停止、缓存变动、错误季/重复集、源越界、伪造 playlist、多个片段/部分区间拒绝、原生命名路径及冲突预检测试。验证模板使用与 13 集完整映射的输出，不执行真实媒体整理。构建清单版本一致，GitHub 下载源码可编译，CI 通过再报告发布完成。不能将离线测试冒称 NAS 安装或实盘播放通过。

用户补充：Disc N 层可以没有。本版选择不新增 Disc 目录，保留 0.4.0 现有的宿主命名实现；盘号只保留在映射和预览中。

实现补充：默认开启仅预览开关，正式整理在调用助手和任何媒体写入前即拒绝；用户确认预览后可关闭。宿主提供完整季集列表时加入总集数核对，防止连续但截短的配对结果被接受。

0.5.2 实盘预览修正：仅容许单主片段+单子路径+单子项、类型10、同文件/codec/STC、无重复或多clip、同步主项0且PTS/入点相同、出点最多差1tick的DV增强层。其他子路径继续拒绝。同季失败短暂60秒抑制重复AI，候选单独保存，校验前标记未通过，不作为成功plan。
