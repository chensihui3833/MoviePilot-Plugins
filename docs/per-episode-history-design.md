# 蓝光逐集任务与整理记录

用户需求：MoviePilot 媒体整理中每集有独立记录，可核对哪集成功/失败。当前0.5.3以盘目录为输入，导出多集但宿主只能按盘任务结算一条。已能播放的硬链接视频与现有命名规则保持。

## Chosen implementation

在现有、已受版本约束的候选规划 adapter 中，把已验证整季映射里的当前盘正片 M2TS 拆为普通文件候选；为每个候选绑定完整季身份和准确集号，让宿主原生 durable admission、执行和结算产生一集一条任务及历史。保留普通电影、普通视频和未启用场景原行为。不通过复制成功记录伪造逐集状态，不直接写宿主数据库。

整季AI分析仍只执行一次，按源快照复用；配对未确认时不能编造集号。此时保留盘级识别失败入口，提示尚未得到可执行逐集表。规划期只读，不建立媒体文件。每次实际执行仍检查最新preview_only，真实源文件、MPLS、完整视频范围、同文件系统与目标幂等状态。

源M2TS作为新任务的真实src_fileitem，meta携带SxxExx；同一视频只属于一集。普通硬链接导出复用原路径命名/NFO逻辑，但每个任务仅导出当前一集。集号来自已验证映射，绝不从00056.m2ts等编号猜测。以单个M2TS进行重试时，重新从其盘/季定位映射，校验季集与TMDB身份，不能触及其他集。删除记录/目标时宿主得到的是单个目标视频，不能把整季/整盘当作该集删除对象。原盘保护要求保持source-only link模式；插件本身不删除视频。

planner的显式meta/下载历史优先级不能覆盖逐集meta：适配_build_file_context并提供精确inherited meta；用真实本地FileItem路径/大小/mtime，不沿用目录fileid。无法取得可靠meta或映射时不让STREAM花絮按普通节目误整理。

## Validation

合成整季：非数字顺序映射拆为正确逐集候选；普通项透传、显式meta与直接M2TS重试身份正确、未知视频拒绝。每集单独执行记录/失败，某一集目标冲突仅该集失败，其余成功；取消与重试幂等，所有成功目标samefile源文件；preview不产生文件或历史。重载不叠adapter、停用恢复原函数。现有80项回归保留。

现场验收先更新源并安装，预览辐射应8个真实源M2TS候选而非3个盘输入。对已经存在的8集以同文件校验的幂等单集整理产生真实8条记录，不删除/重建视频；比对8项inode/NFO不变。原3条盘级历史保留为旧版本证据；若要清除旧记录，先展示新8条与备份旧3条，再按产品的永久删除确认要求由用户确认，只删除记录不删目标或源。

## Limits

继续限定>=3.1.5,<3.1.7私有planner接口。未知菜单分析失败可能只能有盘级识别错误记录，因为尚无法证明具体集号；不冒称已拥有逐集配对。现有盘级durable历史不改写为冒充单集任务；新任务以真实源M2TS形成独立durable身份。
