# 蓝光电视剧分集（BlurayEpisodes）0.6.0

基于原 **Codex 版 0.4.0**，保留媒体匹配、MoviePilot 命名、原生整理预览、硬链接及 NFO 输出，将分集识别改为调用 MoviePilot 已配置的智能助手。

## 安装与预览

插件源仍为本仓库，原生 V3 索引为 `package.v3.json`（源码在 `plugins.v3/blurayepisodes`），同时保留旧布局以兼容来源记录。在 MoviePilot 插件市场安装或更新 **蓝光电视剧分集（BlurayEpisodes）0.6.0**。请区分另一款 **蓝光原盘分集（BlurayEpisodeSplit）**，不要同时启用两个整理接管插件。

1. 在系统设置启用并配置智能助手，确认模型调用测试成功。
2. 启用本插件，保持默认的 **仅预览** 开关开启。
3. 到 **文件管理** 选择完整一季的原盘下载目录，选择 **整理 → 预览**。
4. 核对逐集源视频、季集号、目标文件名和匹配结果。首次需等待助手分析整季；同一源内容的后续各盘复用结果。
5. 只有核对并决定正式整理后，再关闭“仅预览”。该开关开启时，正式整理会明确拒绝，不会创建媒体硬链接。

升级不会主动扫描或整理原盘；不用另填模型密钥、下载目录或媒体库目录。0.6.0 是需要先预览验收的版本，不代表任意蓝光菜单均已验证。

## 输出

完整沿用 MoviePilot 的目标库、分类和重命名规则，不新增 Disc 子目录。例如：

```text
剧名 (年份)/
  Season 2/
    剧名 - S02E01.m2ts
    剧名 - S02E01.nfo
    剧名 - S02E02.m2ts
    剧名 - S02E02.nfo
```

每一集来自哪张盘保留在插件结果和原生预览里。媒体固定使用同文件系统的硬链接，不复制、移动、删除或覆盖源视频；不退回复制。已有相同硬链接幂等复用，冲突停止。NFO 沿用 0.4.0 的生成和扩充信息保留逻辑。

## 助手与插件的分工

插件给助手整季目录和配对目标，不预填盘数、集数、菜单引擎或旧答案。助手自主分析后，调用 `submit_bluray_mapping` 提交全季集序、集名、光盘号、播放列表和视频、依据及未知项。

插件再读取真实播放列表，核对季号、连续集号、实际盘范围、文件存在性、视频完整范围和已提供的地区分支。宿主提供完整本季集表时，也核对总集数。助手有未知项、没有提交结果、超时或校验失败时，保留原盘并返回待核对，不将一张盘当成一集。

这类文件校验不能独立证明任意菜单的语义完全正确，首次使用仍应核对预览。助手继续受 MoviePilot 自身工具权限约束；插件要求它只分析，但不新增操作系统文件沙箱。

整季结果按源文件状态和元数据哈希缓存；源内容变化后重新分析。默认等待上限 1200 秒，可设 30–3600 秒；停止整理或停用插件会取消等待。同季失败后60秒内不重复调用助手，避免一季多盘依次重复相同失败；保存插件设置可重置此短暂限制。分析候选单独留作诊断，只有校验通过才作为成功缓存。

## 支持边界

- 兼容范围暂限定 MoviePilot **>=3.1.5,<3.1.7**，沿用原 0.4.0 的接管及预览接口。内部 Agent 接口不可用时明确失败，不宣称兼容其他版本。
- 本地目录型 BDMV；完整一季的各盘放在同一个下载目录，支持 `DISC1` 及 `Show.S01.Disc1-Group` 等真实盘目录名，也可从盘内身份确定盘号；无需改名。
- 每集须对应一个完整 M2TS。拼接多个片段、只引用文件的一段、多角度或独立子路径不能通过整文件硬链接等价导出，因此停止待核对。同文件、同STC、同步到同一主片段、区间一致（仅允许1 tick舍入差）的类型10杜比视界增强层可以保留：完整M2TS硬链接包含其中所有流。
- ISO 不支持直接分集。远程网盘没有本地硬链接语义，不在本版接管范围。
- 运行环境须有 `ffprobe`，源与目标须在同一文件系统，账户具备硬链接权限。
- MoviePilot 原生重新整理或其他联动清理发生在本插件前后的行为，不能由本插件替代控制。测试请使用预览。

## 逐集整理记录（0.6.0）

已验证的蓝光配对在提交前拆为逐集原生任务，媒体整理历史以真实 M2TS 为源路径，每集各一条成功/失败记录，可按集重试。视频仍按 MoviePilot 模板生成硬链接和 NFO；不改变原盘，不靠复制整盘成功状态生成记录。单集输出冲突不会导致其他集的成功被合并成整盘失败。

配对尚未确认时仍需记录盘级识别失败，因为不能编造该盘集号。旧版本已有盘级记录不会自动删除；升级后产生的逐集记录是独立真实任务。若使用旧盘级失败记录的冻结重试，插件会提示改从文件管理重新预览，以生成新逐集任务。不要用删除原盘来清理历史记录。
