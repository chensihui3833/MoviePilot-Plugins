# MoviePilot 蓝光电视剧分集插件

将受支持的电视剧 BDMV 原盘转换成逐集视频硬链接及 NFO，接入 MoviePilot 原有的自动整理和手动整理。

**0.3.0 为测试版。** 支持 MoviePilot 3.1.5、3.1.6。新版改为静态读取 onQ 菜单脚本、按钮标题与播放状态表，不再根据 `EP`、`SEG_EPL` 等播放列表名称决定集号。使用同一解析器对三季、10 张原盘完成只读验证，分别得到 10、13、10 集；安装后仍应先预览。

## 安装与更新

在 MoviePilot 的插件仓库/插件源设置中追加本仓库的 GitHub 地址，保留原有仓库。找到 **蓝光电视剧分集（BlurayEpisodes）** 并安装，然后打开插件的“启用蓝光电视剧自动分集”开关。

不需要在插件中另填下载目录、媒体库目录，也不需要每次单独执行导出。

以后更新会同时修改根目录 `package.json` 的版本号和插件类 `plugin_version`。MoviePilot 从同一个仓库获取更新。若希望自动安装更新，还需启用并配置 MoviePilot 中的插件自动更新功能；仅添加仓库并不代表已开启自动更新。

插件更新前应等待现有整理任务结束。初次使用先做原生整理预览，再正式整理。

## 工作方式

1. 对本地 `DISC1`、`DISC2` 等 BDMV 盘目录，沿用上一级整季目录中的剧名与季号，再由 MoviePilot 识别媒体并选择目标媒体库。
2. 插件接管本地电视剧 BDMV 目录，读取整季所有盘的菜单和播放列表。
3. 核对按钮标题与播放函数使用的集号，读取脚本中的盘号、各盘集数、区域状态与播放资源，核对视频起止时间。
4. 根据原来的分类目录和命名模板，为当前盘生成对应的逐集 `.m2ts` 硬链接及 NFO。
5. MoviePilot 处理整理历史及完成事件；Emby 扫描后可逐集入库。

关闭插件后，新任务恢复 MoviePilot 原来的整理行为。普通电影和普通单集视频不受影响。

输出示例：

```
剧名 (年份)/
  Season 1/
    剧名 - S01E01.m2ts
    剧名 - S01E01.nfo
    剧名 - S01E02.m2ts
    剧名 - S01E02.nfo
```

命名模板的文件名必须包含 `SxxExx`，并保留 `.m2ts` 扩展名。原生“预览”只读检查，不生成文件；成功盘展开为逐集预览，按实际输出集数统计，并标注来源盘、该盘集数和标题。原生历史仍按每个原盘任务记录，不会变成每集一条历史；结果文件列表包含该盘全部分集文件。

## 支持范围

目前只支持已验证的 Sony/onQ 菜单结构，完整一季放在同一目录下：

```
整季目录/
  DISC1/BDMV/JAR/00002.jar
  DISC1/BDMV/PLAYLIST/*.mpls
  DISC1/BDMV/STREAM/*.m2ts
  DISC2/...
```

- JAR 中须有英文 `RESDIR.QCD`、QCOF v5 菜单脚本及其引用的标题、状态资源。解析器按资源引用读取文件，并核对脚本中已识别的分集函数结构。
- 各盘须有相同的整季标题表和盘数分配；目录盘号必须与脚本声明的盘号一致。按钮标题索引、播放参数、盘内集号转换及实际播放状态须能连接起来。
- 区域 A/B 对应的播放列表必须指向相同视频和时间范围；不同剪辑版本会停止，避免静默选错版本。
- 每集须对应一个完整视频文件。多片段拼接、多角度或只播放视频一部分的情况会停止。
- 需要 `ffprobe` 在 MoviePilot 运行环境的 PATH 中。
- 源和目标必须位于同一文件系统，MoviePilot 账户必须有创建硬链接权限。
- ISO、其它菜单引擎，以及无法静态确认上述关系的脚本不在当前分集范围内。不会因为“有菜单”就宣称支持所有蓝光盘。

插件读取二进制资源和脚本指令，并在严格限步的纯算术分析器中核对跨盘集号转换。该分析器不提供文件、网络、设备或系统调用；遇到不能分析的指令会停止。运行插件不需要 Java 或蓝光导航引擎，也不执行盘内 Java 程序。标题来源于菜单，英文菜单输出英文标题。

上一级目录须能明确识别为单季电视剧，例如 `Show.S01.2020.1080p.BluRay`。不能明确识别时仍需在原来的手动整理窗口指定正确剧名、类型和季号，不会猜测剧名。

## 文件保护

- 固定使用硬链接，即使整理窗口选择移动，也不移动原盘。
- 不删除、不覆盖源视频；不自动退回大文件复制。
- 缺盘、菜单信息不足或目标冲突会返回失败，不回退整盘整理。
- 重复执行复用同一原视频的硬链接；已有同季同集的扩充 NFO 保留。
- 取消时保留已生成入口，可以修复后重试。

硬链接共享视频内容，请勿编辑任一视频文件本身。MoviePilot 原生“重新整理”可能在插件调用之前清理旧目标；其它联动清理插件也可能删除源文件或种子。**上线前必须核对这些外部清理机制**，本插件不能阻止发生在自身调用之前的清理。

## 开发与验证

```
python -m unittest discover -s tests -v
```

测试涵盖合成菜单程序解析、无集号资源名称、标题/播放绑定错误、纯算术分析中的外部调用拒绝、资源截断、区域版本冲突，以及缺盘、源文件保护、开关、只读预览、逐盘输出、重复执行及取消。测试使用独立临时目录，不需要 MoviePilot 服务或真实蓝光文件；仓库不包含商业原盘脚本或反编译代码。

分集接入点为 `get_module()["transfer"]`。另对整理候选规划器 `_build_path_meta` 加入范围受限的运行时兼容适配，解决 `DISC1` 被当成剧名的问题；对 `_TransferSubmissionCollector.result` 的只读预览展开成功盘的实际输出。停用时恢复，不修改主程序磁盘文件。路径计算复用主程序辅助函数，因此兼容范围暂限定 `>=3.1.5,<3.1.7`。主程序升级后需重新核对接口。
