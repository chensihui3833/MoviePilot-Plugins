# MoviePilot 蓝光电视剧分集插件

将受支持的电视剧 BDMV 原盘转换成逐集视频硬链接及 NFO，接入 MoviePilot 原有的自动整理和手动整理。

**0.2.1 为测试版。** 支持 MoviePilot 3.1.5、3.1.6；已核对这两个版本的调用接口。两种版本已完成安装，原生整理验收仍在进行。

## 安装与更新

在 MoviePilot 的插件仓库/插件源设置中追加本仓库的 GitHub 地址，保留原有仓库。找到 **蓝光电视剧分集（BlurayEpisodes）** 并安装，然后打开插件的“启用蓝光电视剧自动分集”开关。

不需要在插件中另填下载目录、媒体库目录，也不需要每次单独执行导出。

以后更新会同时修改根目录 `package.json` 的版本号和插件类 `plugin_version`。MoviePilot 从同一个仓库获取更新。若希望自动安装更新，还需启用并配置 MoviePilot 中的插件自动更新功能；仅添加仓库并不代表已开启自动更新。

插件更新前应等待现有整理任务结束。初次使用先做原生整理预览，再正式整理。

## 工作方式

1. 对本地 `DISC1`、`DISC2` 等 BDMV 盘目录，沿用上一级整季目录中的剧名与季号，再由 MoviePilot 识别媒体并选择目标媒体库。
2. 插件接管本地电视剧 BDMV 目录，读取整季所有盘的菜单和播放列表。
3. 核对标题、盘内 EP、完整盘序和视频起止时间。
4. 根据原来的分类目录和命名模板，为当前盘生成对应的逐集 `.m2ts` 硬链接及 NFO。
5. MoviePilot 处理整理历史及完成事件；Emby 扫描后可逐集入库。

关闭插件后，新任务恢复 MoviePilot 原来的整理行为。普通电影和普通单集视频不受影响。

输出示例：

```
剧名 (年份)/
  Season 1/
    剧名 - S01E01.m2ts
    剧名 - S01E01.nfo
    剧名 - S01E02.m2ts
    剧名 - S01E02.nfo
```

命名模板的文件名必须包含 `SxxExx`，并保留 `.m2ts` 扩展名。原生“预览”只读检查，不生成文件。原生历史仍按每个原盘任务记录，不会变成每集一条历史；结果文件列表包含该盘全部分集文件。

## 支持范围

目前只支持已验证的 Sony/onQ 菜单结构，完整一季放在同一目录下：

```
整季目录/
  DISC1/BDMV/JAR/00002.jar
  DISC1/BDMV/JAR/00002/playlists.xml
  DISC1/BDMV/PLAYLIST/*.mpls
  DISC1/BDMV/STREAM/*.m2ts
  DISC2/...
```

- 各盘必须有相同、完整、连续的英文标题表 `eng/tblEP_T3_01_res.qct` 等。
- 盘号及每盘主 `EP 1`、`EP 2` 播放列表项必须连续。
- 每集须对应一个完整视频文件。多片段拼接、多角度或只播放视频一部分的情况会停止。
- 需要 `ffprobe` 在 MoviePilot 运行环境的 PATH 中。
- 源和目标必须位于同一文件系统，MoviePilot 账户必须有创建硬链接权限。
- ISO 和其它菜单结构不在当前分集范围内。

插件根据上述菜单结构的盘序、盘内 EP 顺序和整季标题表建立对应关系，不执行 JAR 中的程序，也不按视频文件大小猜集号。标题来源于菜单，英文菜单输出英文标题。

上一级目录须能明确识别为单季电视剧，例如 `Show.S01.2020.1080p.BluRay`。不能明确识别时仍需在原来的手动整理窗口指定正确剧名、类型和季号，不会猜测剧名。

## 文件保护

- 固定使用硬链接，即使整理窗口选择移动，也不移动原盘。
- 不删除、不覆盖源视频；不自动退回大文件复制。
- 缺盘、菜单信息不足或目标冲突会返回失败，不回退整盘整理。
- 重复执行复用同一原视频的硬链接；已有同季同集的扩充 NFO 保留。
- 取消时保留已生成入口，可以修复后重试。

硬链接共享视频内容，请勿编辑任一视频文件本身。MoviePilot 原生“重新整理”可能在插件调用之前清理旧目标；其它联动清理插件也可能删除源文件或种子。**上线前必须核对这些外部清理机制**，本插件不能阻止发生在自身调用之前的清理。

## 开发与验证

```
python -m unittest discover -s tests -v
```

测试涵盖解析、缺盘、错误标题、多片段、源文件保护、冲突、开关、只读预览、逐盘输出、重复执行及取消。测试使用独立临时目录，不需要 MoviePilot 服务或真实蓝光文件。

分集接入点为 `get_module()["transfer"]`。0.2.1 另对整理候选规划器 `_build_path_meta` 加入范围受限的运行时兼容适配，解决 `DISC1` 被当成剧名的问题；停用时恢复，不修改主程序磁盘文件。路径计算复用主程序辅助函数，因此兼容范围暂限定 `>=3.1.5,<3.1.7`。主程序升级后需重新核对接口。
